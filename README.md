# SIZA Apps Website

Static, responsive website for SIZA Apps.

## Files
- `index.html` — main business website
- `styles.css` — complete responsive styling
- `script.js` — mobile navigation and reveal animations
- `privacy.html` — draft privacy landing page
- `support.html` — support page suitable for linking from app stores
- `terms.html` — draft terms page
- `assets/` — SIZA and Community Events imagery

## Deploy
Upload the full contents of this folder to the web root for `siza.info` using Firebase Hosting, Cloudflare Pages, Netlify, GitHub Pages, cPanel, or another static host.

For Firebase Hosting, a developer can initialise hosting and set the public directory to this folder (or copy these files into the configured public directory).

## Important before app-store submission
The included Privacy Policy and Terms pages are intentionally marked as drafts. Replace or merge them with the final legally reviewed policies before using those URLs as official app-store legal links.
